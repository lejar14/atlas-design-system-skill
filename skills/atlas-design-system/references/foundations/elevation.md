# Elevation
Subtle shadow tokens for layered UI depth — from flat surfaces to modals and popovers.
### Elevation
Level 0 - Flat
No shadow. Default surface.
Level 1 - Raised
Cards, panels.
Level 2 - Elevated
Dropdowns, hovercards.
Level 3 - Overlay
Popovers, tooltips.
Level 4 - Modal
Modals, dialogs.
