# Avatar
An avatar visually symbolizes users or characters. Designers incorporate avatars to customize the user experience by showing a profile image or distinctive icon for each user, and to distinguish user roles like customers or administrators.
### Base
Every avatar type — Icon, Logo, Memoji, Initial, Picture — across all 6 status colors, at every size in our size scale.
